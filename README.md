# Simulador MAAT - GitHub Pages

Primera versión funcional de una evaluación interactiva basada en el flujo del material MAAT V2.2.16.

## Archivos
- `index.html`
- `styles.css`
- `app.js`

## Cómo publicarlo gratis en GitHub Pages

1. Entra a https://github.com
2. Crea un repositorio nuevo, por ejemplo:
   `SIMULADOR-MAAT`
3. Sube los tres archivos:
   - index.html
   - styles.css
   - app.js
4. En el repositorio entra a:
   **Settings > Pages**
5. En "Build and deployment":
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Guarda.
7. GitHub generará una dirección similar a:
   `https://TU-USUARIO.github.io/SIMULADOR-MAAT/`

## Qué incluye esta versión
- Registro de nombre, Pandape y región.
- 10 casos basados en el flujo MAAT.
- Interfaz tipo simulador.
- Calificación automática sobre 100.
- Retroalimentación por pregunta.
- Desglose por tema.
- Temas a reforzar.
- Descarga local del resultado en TXT.
